# 扩展指南

在 [Hello World](/vscode/extension/get-started/your-first-extension) 示例中学习了 Visual Studio Code Extension API 的基础知识之后，是时候构建一些真正的扩展了。[扩展能力](/vscode/extension/extension-capabilities/overview)章节提供了扩展**能**做什么的高层概述，而本章节包含一系列详细的代码指南和示例，讲解**如何**使用特定的 VS Code API。

在每个指南或示例中，你将看到：

- 详细注释的源代码。
- 展示示例扩展用法的 GIF 或图片。
- 运行示例扩展的说明。
- 所使用的 VS Code API 列表。
- 所使用的 Contribution Points 列表。
- 与示例类似的实际扩展。
- API 概念的解释。
